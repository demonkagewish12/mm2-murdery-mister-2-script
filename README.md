## 🛠️ Как использовать (только ПК)

1. Скачай любой рабочий executor (Solara, Wave, Delta и т.д.)
2. Зайди в **Murder Mystery 2**
3. Заинжекть executor
4. Скопируй скрипт выше и вставь в executor
5. Нажми **Execute**
6. Откроется GUI — включай нужные функции
